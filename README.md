# AURUM DETAIL

Демонстрационный сайт вымышленной студии автомобильного детейлинга в Санкт-Петербурге. В проекте используются HTML, CSS и JavaScript. Все изображения хранятся локально.

## Запуск

Откройте `index.html` двойным щелчком в актуальном браузере. Для просмотра достаточно сохранить структуру папок проекта.

При необходимости можно запустить локальный HTTP-сервер из папки проекта с помощью уже установленного Python.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

В браузере откройте `http://127.0.0.1:8000/`. В текущей среде Codex вместо команды `python` можно использовать встроенный интерпретатор.

```powershell
& 'C:/Users/user/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' -m http.server 8000 --bind 127.0.0.1
```

## Дизайн-система

- Графит `#101010`, тёплая панель `#171615`, шампань `#d6bb90`, основной текст `#f4efe8`.
- Системный гротеск для заголовков и текста, курсив Georgia для акцентов, моноширинные подписи.

## Демонстрационные данные

Контактный email и ссылки на Telegram и WhatsApp находятся в секции `#contacts` файла `index.html`. Ссылки на мессенджеры открывают их общедоступные страницы. Все фотографии сгенерированы для демонстрации. Форма проверяет поля в браузере и показывает результат проверки без отправки или сохранения данных.

## Превью ссылки после публикации

Когда сайт появится на реальном домене, добавьте в `<head>` файла `index.html` метаданные Open Graph.

- `og:url` — полный HTTPS-адрес опубликованной страницы.
- `og:image` — полный HTTPS-адрес доступной без входа обложки проекта.
- `og:image:alt` — краткое текстовое описание обложки.

Проверьте, как выглядят существующие `og:title` и `og:description` вместе с обложкой при отправке ссылки.

## Структура

- `index.html` — содержимое, навигация, метаданные и форма.
- `styles.css` — визуальные правила, адаптивность и анимации.
- `script.js` — мобильное меню, галерея, выбор услуги и обработка формы.
- `assets/` — знак студии и оптимизированные изображения WebP.
